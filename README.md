# Synthesize ($SYNTH)

AI-powered drug discovery and autonomous pharmacology laboratory.
Design molecules. Simulate treatments. Discover the future of medicine.

## Files
- `index.html` — the full site (Discovery lab, Experiments, Research notebook, $SYNTH)
- `logo.png` — logo and favicon
- `middleware.js` — Vercel middleware that powers the research notebook at `/api/notebook`
- `vercel.json` — Vercel config

## Deploy on Vercel
1. Push these files to the root of a GitHub repo and import it in Vercel (Framework preset: **Other**, no build command).
2. In Vercel → Project → Settings → Environment Variables, add `ANTHROPIC_API_KEY`.
3. Redeploy.
